- **Promoted frontier champion (Oct 31, source SHA `576af9c23bbbdfa16838a4737342ab2063176615`):** parallel bucketed parse and CSR build, BFS-region renumbering for locality, 4-byte packed edges with exact escape table, exact-key bucket queue, paged per-worker labels, queries scheduled by source id. Local 4-core VM, full seed 1, interleaved A/B against the previous champion: median wall **0.33 s vs 1.10 s (3.3x)**, peak RSS **91 MB vs 227 MB**, exact output SHA `a23dbdf0...` every run. Not scoring-box data; the scoring box has 12 threads, so parallel phases should scale further.
- **Independent Chat qualification (Oct 31):** [successful matched CI](https://github.com/insightlabs38-pixel/sd-td/actions/runs/41151166030), branch `d/frontier-independent-qualification`, is source-identical to promoted `576af9c` (only the workflow differs). Seven interleaved full-seed-1 passes, all exact SHA: previous champion median wall **0.96 s**, frontier **0.29 s** (**3.31x faster**); median peak RSS **227,320 to 87,944 KiB** (**61.3% less**); median user CPU **2.77 to 0.96 s**. Full seed 2 matched the official Python reference byte-for-byte (output SHA-256 `23d60c06b8e2c6086f765e4a9a3640306c3bf8199149fd39b20e1ef56b3b8a4b`); 120 additional lattice stress seeds, 83 differential fixtures, official tiny/sample/full seed-1 and offline Docker sample/full checks all passed. Rough nonblank noncomment C++ lines grew 292 to 512; estimated combined T/M/S K ratio about **2.0x** under published exponents, not an official board or scoring-box result.
- **Gates:** 83 differential cases x 3 thread counts x 6 probe limits; tiny seed 2 and sample seed 2 byte-identical to the Python reference; sample seed 1 and full seed 1 SHA match the published values; ASan/UBSan clean; pinned Docker build and run match ([CI run](https://github.com/insightlabs38-pixel/sd-td/actions/runs/41148327539)).
- **Measured by phase (4 threads, ms):** parse+bin 30, raw CSR 15, BFS regions 35, assemble 8, gather 22, reverse 23, queries ~150. Single-thread query CPU ~0.6 s for 7.4M settles.
- **Findings:** random relabeling made every label access a cache miss; BFS renumbering alone cut query CPU 2.4x. A shared claim bitmap was fine, but adjacent per-region counters false-shared and cost 2x until moved to locals. Atomic CSR scatter cost 85 ms vs 15 ms for bucketed no-atomic build. Packed/Dial-style queues helped only once the bucket array was lean. Transparent huge pages gave a small median gain but a bad tail on this VM, so they were removed. A forward probe of 256 settles is required: pure bidirectional search floods the 1.7M-node main component for island-source queries.
